A single deadpan safety notice for a time machine, written to get a laugh:
passengers are warned not to look out the window in transit, because the
passenger staring back at them is themselves — holding their return ticket
hostage. A real hazard of time travel (a duplicate self, a stranded
traveller) turned into the joke, with the surprise saved for the last word.

## The label

> WARNING: Do not look out the window in transit. The passenger staring back is you, holding your return ticket hostage.

118 characters — inside the 120-character limit.

## Run

```sh
python3 main.py
```

This writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when set),
with no trailing newline. The program asserts the label is 1–120 characters
before writing.
